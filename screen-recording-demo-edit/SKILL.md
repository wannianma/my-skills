# 录屏演示视频剪辑：功能放大 + 配音讲解

把一段产品操作录屏剪成演示视频。用户点到哪个功能就平滑放大哪块，配一句讲解和标签。原视频的声音（比如演讲、背景音）在讲解时压低，其余时候正常播放，保留“在看视频”的感觉。

工具：ffmpeg、Python（numpy、opencv-python、Pillow）、edge-tts（免费神经语音合成）、CJK 字体（fonts-noto-cjk）。

## 1. 准备
- 把源视频复制到工作目录，用 `ffprobe` 记下分辨率、帧率、时长、有没有音轨。
- 先确认目标：放大哪些功能、配音用什么语言和风格、成片大概多长、要不要竖屏。

## 2. 还原时间线（最关键，不能偷懒）
录屏通常没有鼠标指针，点击只能从界面变化反推。
- 抽帧：全片每秒 2 帧，可疑处每秒 10 帧，用 `ffmpeg -ss T -i src -vframes 1` 或 `fps=2` 导出 PNG，逐张看图。
- 找变化：弹窗出现、按钮变色、标签切换、文字被遮住等。变化出现的那帧就是点击时间，变化的区域就是放大目标。必要时对固定按钮区域做像素差，精确定位到 0.1 秒。
- 交叉验证：用 `silencedetect` 找视频暂停（很多 App 弹窗时会暂停播放），用带逐词时间戳的语音转写（faster-whisper）定位台词，方便只在句子之间下刀。
- 视频理解模型给的时间线只能当草稿，必须按截图逐条核对。它可能漏掉操作，也可能编出根本没发生的操作。
- 产出：一张表，列出源时间、操作、放大区域（像素框）、可剪掉的空闲段。

## 3. 写剪辑决策表（EDL）
- `SEGS`：保留的源片段列表。切掉长时间无操作、掌声、片尾冗余。每个切口做约 0.35 秒交叉淡化，只在句子边界下刀。
- 写一个 `s2o(源时间)` 函数，把源时间映射到成片时间，后面所有放大、配音、标签都用成片时间。

## 4. 配音
- 每个功能一句，短、直白，说清这个功能干什么、对用户有什么用。开头一句总介绍，结尾一句收束。
- 用 edge-tts 生成音频，中文常用 `zh-CN-YunxiNeural`（男声）或 `zh-CN-XiaoxiaoNeural`（女声），语速约 +10%~+15%。
- 量出每句时长，安排在功能出现时开始。优先塞进原视频的静音或暂停处。不要盖住原片里用户自己的声音或关键台词。

## 5. 放大效果（逐帧渲染）
原理：每帧从原画面裁一块区域，再缩放回原尺寸。区域越小，放大越多。
- 每个放大目标定义为窗口 `(x0, y0, w)`，高度按画面宽高比算，保证不变形。
- 关键帧列表 `KEYS = [(t, window), ...]`，相邻关键帧之间用缓动（ease-in-out cubic）插值。中心点线性插值，宽度在对数空间插值，这样推拉速度看起来均匀。推近和拉远各约 0.4~0.6 秒。
- 用 `cv2.warpAffine` 做亚像素缩放平移，放大时用 `INTER_CUBIC`，边缘用 `BORDER_REPLICATE`。
- 放大倍数一般 1.5~2 倍。源分辨率低时别超过 1.7 倍，否则字会糊。
- 一个功能涉及两处时（比如先点标签、结果出现在下方），先框住标签，再平移到结果区域。
- 点击位置叠一个扩散的半透明圆环（约 0.7 秒），提示“这里点了”。
- 功能标签：用 Pillow 和 CJK 字体画圆角胶囊，比如“词汇卡片 · 点词即查”，淡入淡出各 0.3 秒，放在不挡内容的位置。
- 录屏里固定不动的杂物（悬浮球、通知图标），用旁边一块背景覆盖掉。
- 渲染流程：ffmpeg 解码出 rawvideo 送进 Python，逐帧处理，再通过管道送给 ffmpeg 编码（libx264、crf 18~20、yuv420p）。片段交界处两帧按权重混合，就是交叉淡化。

## 6. 音频
- 原声先用 `dynaudnorm` 把忽大忽小的音量调平，再按 SEGS 拼接，切口做正弦/余弦交叉淡化。
- 压低原声：配音期间（前留 0.35 秒、后留 0.45 秒）把原声增益降到约 0.25，包络做约 0.3 秒平滑，避免突兀。
- 配音统一响度（RMS 约 -19 dBFS），叠上去后过 `alimiter` 防止爆音。
- 目标响度大约 -16~-18 LUFS，峰值低于 -1 dBFS。

## 7. 合成与校验
- 用 `-c:v copy` 合并视频和音频，音频转 AAC 160k，加 `-movflags +faststart`。
- 校验：
  - 每个放大段抽 1 帧看文字是否清楚、框得准不准。
  - 用 `ebur128` 或 `loudnorm` 测响度和峰值。
  - 用 `ffprobe` 确认时长和编码。
  - 有条件就让视频审阅模型看一遍成片。
- 交付：成片 mp4、配音脚本（成片时间 → 功能 → 讲解词 → 标签）、构建脚本（以后改讲解词或放大位置，改参数重新跑就行）。
- 主动告诉用户录屏里缺了哪些功能（没操作到的就不能编），需要的话请他补录。

## 常见坑
- 时间线没核实就开剪，会导致放大落空或讲解对不上画面。
- 放太大，低分辨率录屏的字会糊。
- 讲解和原片的人声重叠，会听不清。
- 不在句子边界下刀，会出现半个词。
- 中文标签没装 CJK 字体，会显示成方块。
